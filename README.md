# Orynex – Planting Advisor Prototype

Interactive prototype of **Orynex**, a flood-risk-informed planting calendar for smallholder rice farmers in the Tamiang floodplain, Aceh (Vocational Championship 2026, Scientific Paper).

The page runs the model from the paper directly in the browser:
- HEC-HMS outlet hydrographs for three land-cover scenarios (11 sub-basins, Senyar storm 397.4 mm)
- seasonal flood hazard from nine documented floods (Jan 2021 – Oct 2026)
- stage-specific submergence vulnerability (conventional vs Sub1 rice)
- two-crop sowing-date optimiser and WhatsApp advisory preview

It is a single static file (`index.html`), no build step and no backend.
Figures are indicative and do not replace BMKG or BPBD warnings.
